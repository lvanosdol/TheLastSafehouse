# Chapter 1: Previous operating system and Windows lessons

**Status:** Historical. These separate lessons were combined in the [current Chapter 1 design](../Chapter%201/Chapter-1-Design.md).

3. **What an operating system does:** Explain how an operating system connects software and hardware and manages devices, disks, applications, and access. Briefly compare desktop, mobile, server, and embedded systems. **Checkpoint:** Identify the operating system's role and distinguish a working Windows desktop from an unresponsive Workshop application.
4. **Using Windows:** Explore the desktop, Start menu, taskbar, Settings, notifications, and graphical interface. Introduce system utilities, running processes, background services, and device drivers. Explain that a command line is another interface without requiring the player to use one. **Checkpoint:** Find Settings and File Explorer and identify a running application or background service in a simulated example.
