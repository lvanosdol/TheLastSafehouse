# Chapter 1: Previous account-creation checkpoint

**Status:** Historical. The [current Chapter 1 design](../Chapter%201/Chapter-1-Design.md) uses a fictional sign-in instead.

In simulated Settings, use an existing authorized administrator account to add a standard account. Then use that standard account in a prepared practice area to create an evidence copy of a practice log in simulated File Explorer, leaving the original intact without changing permissions. The exercise creates no real account and changes nothing on the player's device.
