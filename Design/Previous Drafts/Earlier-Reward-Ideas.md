# Earlier Reward Ideas

**Status: Historical archive.** These ideas were superseded by the seven-agent development app and are not current rewards.

## Console Repair help and bonus

These Logic Chip/Console Repair bonus rules belong to the previous Chapter 1 boss.

- During any of the three Console Repair challenges, requesting a hint or opening the tutor first presents a warning.
- Canceling the help request preserves Logic Chip bonus eligibility.
- Confirming help allows the player to proceed but forfeits the Logic Chip bonus for that chapter run.
- A failed code run on any repair also forfeits the bonus, but does not prevent finishing the story.

## Previous agent roster

The roster was flexible; it did not imply seven agents or seven chapters.

- **Scout:** Organizes/sorts incoming signals, identifies missing context, sorts high-to-low priority, and flags `warning`/`offline`; does not decide actions.
- **Sentinel:** Main detection and triage work; can suggest the best course of action or next steps for the player.
- **Archivist:** Preserves records and builds incident timelines.
- **Watcher:** Looks for unusual times and unfamiliar devices.
- **Relay:** Passes structured findings between agents.
- **Brief:** Converts technical findings into human-readable reports.
- **Verifier:** Checks evidence, tests, and claims before a report is finalized.

## Previous Chapter 2 rewards

Standard Chapter 2 rewards:

- **Failed Login Detector:** Detects repeated failures against one account, many accounts targeted from one source, repeated attempts in a short period, and sudden increases in failed activity.
- **Unusual-Time Detector:** Flags activity outside an established schedule, during a known quiet period, or after a long inactive period. It flags for review rather than declaring activity malicious.
- **Sentinel agent blueprint:** Sentinel performs the main detection and triage work.
- **Signal Shards:** Crafting material for Sentinel; distinct from either Array.

Perfect-run bonus upgrades:

- **Console Core:** Python execution and reusable utilities.
- **Intake Array:** Upgraded log intake and organization, distinct from the standard Intake Component and the story Signal Shard Array.

Previous reward categories:

- **Standard components** build the baseline toolkit.
- **Bonus items** upgrade the toolkit with better capabilities, clearer explanations, stronger tests, and additional customization.
- **Agent blueprints** contribute to a coordinated Sentinel Agent Workshop that can assemble a reliable team.
- Tools are intended to be useful defensively outside the game; real-world testing, safety, and reliability are still required.

The earlier Chapter 2 summary included a guided Sentinel craft using the blueprint and Signal Shards.
