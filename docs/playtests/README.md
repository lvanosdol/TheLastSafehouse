# Playtest Reports

The **Playtester** agent writes one report per testing session here, named `YYYY-MM-DD-topic.md`.

Each report covers: what was run and how, pass/fail per checkpoint, bugs with reproduction steps, difficulty/fun observations from a beginner's perspective, and suggested fixes in priority order.

Reports verify the game against the design's teaching rules (checkpoint loop, hint ladder, unlimited penalty-free retries) — not just whether it runs.
